# Clean style print tests

Four tests generated with the built-in image generation tool. Print clean-style-tests-print.svg at 100% / actual size. All unit image boxes are 40 mm wide; infantry boxes are 13.5 mm tall and mounted boxes 20 mm tall. Mounted proportions are compressed in the print layout to suit the miniature format. Original PNGs are unchanged. The 40 mm rule checks printer scaling.

Gondor cavalry has a white background after the transparent-background edit failed. Other outputs use transparent backgrounds. Physical print quality has not yet been tested.
