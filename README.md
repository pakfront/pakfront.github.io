# Pakfront.github.io

Tools and demos for tabletop and hex-and-counter games.

## Tools

### [Kriegsspiel Map Room](kriegsspiel-map-room/)
Manage battlefield truth and commander views, then export player maps. A desktop umpire tool.

### [Paper Army Standees](paper-army-standees/)
Create printable standees for Midgard Heroic Battles and other tabletop games.

Images are stored in regular Git. GitHub Pages does not support Git LFS.
