# Pakfront.github.io

Tools and demos for tabletop and hex-and-counter games.

## Tools

### [GCACW Combat Aid](gcacw-combat-aid/)
Calculate combat modifiers for Great Campaigns of the American Civil War, with a visual flanking and zone-of-control helper.

### [Kriegsspiel Map Room](kriegsspiel-map-room/)
Manage battlefield truth and commander views, then export player maps. A desktop umpire tool.

### [Midgard Army Workshop](midgard-army-workshop/)
Build a Midgard Heroic Battles roster and print matching paper miniatures, or choose standees directly from the historical and Middle-earth catalogs.

Images are stored in regular Git. GitHub Pages does not support Git LFS.
